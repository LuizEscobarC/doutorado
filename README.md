# Doutorado

Repositório público do meu doutorado: revisão de literatura, experimentos, artigos e tese.

## Estrutura

- `docs/` — escrita (tese, artigos, notas), em Markdown/LaTeX
- `experiments/` — experimentos reprodutíveis em Python
- `refs.bib` — referências em BibTeX

## Convenções

- Texto em PT-BR (artigos podem ser em inglês), sem emojis.
- Toda afirmação da tese cita fonte.
- Experimentos com seed fixa e dependências travadas.
- Repo público: nada de dado pessoal, credencial ou dado sensível de terceiros.
